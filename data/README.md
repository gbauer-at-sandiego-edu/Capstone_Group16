# GeoLife GPS Trajectory Dataset — Data Documentation

This project uses the Microsoft GeoLife GPS Trajectory Dataset (Version 1.3), a large-scale collection of real-world GPS trajectories recorded by 182 users over a five-year period. The dataset contains more than 17,000 trajectories covering over 1.2 million kilometers of movement, with sampling intervals typically between 1–5 seconds. Each trajectory includes latitude, longitude, altitude, and timestamp information, enabling the derivation of kinematic features such as speed, heading, acceleration, and turn rate.

## Data Storage Notice

The raw GeoLife dataset is not included in this repository due to size and licensing constraints.  
To run the preprocessing pipeline or notebooks, download the dataset directly from Microsoft Research:

Microsoft Research Asia. (2012). GeoLife GPS Trajectory Dataset (Version 1.3).  
https://www.microsoft.com/en-us/research/project/geolife-building-social-networks-using-human-location-history/

Place all downloaded `.plt` files under:

```
data/raw/
```

This directory is intentionally empty in the repository.

## Processed Data

The `data/processed/` directory will be automatically populated once the preprocessing pipeline is run.

Depending on configuration, this directory may contain:

- Parquet chunks generated by `geolife_pipeline_enhanced.py`
- A final unified parquet dataset
- Error logs for problematic `.plt` files
- Optional sample CSVs created during development

No processed data is included in the repository by default.

## Preprocessing Code

The `src/` directory contains all modules used to load, clean, and transform GeoLife trajectory data:

- `load_plt.py` — PLT file loader that parses timestamps, removes duplicates, and returns a cleaned DataFrame.
- `processing.py` — Resampling, UTM projection, kinematic feature computation, and schema enforcement.
- `geolife_pipeline_enhanced.py` — Main multiprocessing pipeline that processes all `.plt` files under `data/raw/` and writes parquet chunks.

These modules expect the dataset to be located under `data/raw/`.
